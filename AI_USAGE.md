# AI Usage

AI tools were used as development assistants during this assignment.

## Areas Where AI Helped

- Understanding the assignment requirements and planning the project structure.
- Troubleshooting Hugo templates, configuration, and build issues.
- Assisting with Sanity schema design and content synchronization.
- Reviewing semantic HTML, accessibility, and responsive design considerations.
- Preparing project documentation and setup instructions.

## Human Review

Generated suggestions were reviewed and tested during implementation. Project code and configuration were adjusted as needed to match the assignment requirements.

## Limitations and Trade-offs

AI-generated suggestions may require corrections to work with the installed versions of Hugo, Sanity, Node.js, and Sass. The application was tested locally during development, and deployment and final acceptance checks should be completed separately.
